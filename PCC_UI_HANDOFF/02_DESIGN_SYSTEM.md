# PCC Design System — Implementation Tokens

## Typography
Preferred family: Inter.

- Display: 32px / 40px / 700
- Heading 1: 24px / 32px / 600
- Heading 2: 18px / 26px / 600
- Body: 14px / 20px / 400
- Body Medium: 14px / 20px / 500
- Small: 12px / 16px / 400
- Label: 12px / 16px / 600

Use the repository's existing font setup if replacing it would create unnecessary churn.

## Radius
4, 6, 8, 12, 16

## Elevation
Use shadows sparingly.
Default card: roughly 0 2px 8px rgba(15,23,42,0.08)

## Desktop Philosophy
- high information density
- strong alignment
- clear grouping
- compact operational controls
- tables over decorative card grids where scanning matters
- sticky headers/filters where they improve daily usage

## Mobile Philosophy
- field operations first
- 48px target height for primary controls
- avoid dense desktop tables
- keep job + PO identity visible
- make receiving quantities and exceptions easy to operate
