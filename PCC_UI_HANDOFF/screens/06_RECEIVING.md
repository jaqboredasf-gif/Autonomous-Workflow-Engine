# Screen 06 — Receiving
Primary users: assigned/authorized foreman; authorized purchasing.

MOBILE-FIRST.

Persistent identity:
PO #
Job
Vendor/status as useful

For each item:
- ordered qty
- previously received
- receiving now
- remaining
- condition/exception

Receipt outcomes:
- complete
- partial
- damaged
- incorrect
- missing

Evidence:
- photo
- delivery slip/receipt
- note

Confirm action must be large and clear.

Partial receipt must not close the PO.
Authority must be enforced, not merely presented visually.
