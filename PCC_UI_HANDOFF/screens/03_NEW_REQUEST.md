# Screen 03 — New Request
Primary users: Requester, Foreman.

Fields:
- Job
- Needed By
- Priority: Normal / Urgent / Emergency
- repeating item rows
- material
- quantity
- unit
- optional preferred vendor
- notes
- attachments

Material entry:
- canonical catalog autocomplete
- aliases
- frequently/recently ordered materials prioritized
- manual entry allowed if catalog lacks item
- selection should preserve canonical material ID when selected

Actions:
Save Draft
Submit Request

Do not make the form visually heavy; speed matters.
