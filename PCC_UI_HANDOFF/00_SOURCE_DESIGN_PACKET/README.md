# PCC Design Packet v1

This packet is the portable design/specification source of truth for the PCC before additional Figma work.

Files:
- 01_PCC_Design_System.md — visual foundations and interaction rules
- 02_PCC_Component_Library.md — reusable component contracts
- 03_PCC_Screens_01-10.md — complete product screen specifications
- 04_PCC_Figma_Handoff.json — exact Figma continuation order and hard rules
- 05_PCC_Business_Rules_Handoff.md — implementation-facing business rules already established

Use:
1. Treat these artifacts as authoritative requirements.
2. Figma should visualize them, not redesign them.
3. Claude Code should implement them, not invent product behavior.
4. Any conflict should be surfaced rather than silently resolved.
