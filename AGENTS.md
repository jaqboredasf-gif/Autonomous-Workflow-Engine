# Repository Agent Rules

- Read `docs/planning/AGENT_HANDOFF.md` before starting.
- Update it before ending every meaningful task.
- Commit and push verified work.
- Open a draft PR for each major task.
- Never place secrets in the handoff or Git.
- Never apply live migrations without explicit approval.
- Work on one major task per branch.
- Stop when repository, migration history, and live state disagree.
