# Competition intelligence — Iona Innovation Challenge 2027

**Status: NOT RESEARCHED.** This file is a structure with the questions in it, and it is committed
empty on purpose.

Filling it in with plausible-sounding assumptions about a real competition would be the same
failure this repository's proof architecture exists to prevent, applied to a different subject:
a confident statement with no source. So the fields below are questions until somebody answers them
from the competition's own materials or from a person who ran it.

## Product alternatives — a separate question, and the one that matters more

Not competitors in the contest. What a trades business would actually buy instead.

|---|---|---|---|
| — | | | |

This table is what `differentiation` in the readiness scorecard is scored against, and it is
currently band 0 for exactly this reason. It is also one of the cheapest bands in the whole
scorecard to move: three named alternatives and one honest sentence.

**The sentence to aim for** — testable today, and rare in the category:

> Most workflow tools report that a task completed. AWE reports whether the organization's
> objective was achieved, which is a different question, and it can show you the difference.

Do not write that into a pitch until the alternatives table is filled in and the claim survives it.
