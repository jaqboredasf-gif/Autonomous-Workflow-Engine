# Mock pitches

One file per delivery. Fill in the field sheet from **what the listener said**, not from how it
felt.

A record with nothing the listener said is kept and counts as a **rehearsal**, not a mock pitch.
Practising alone is a real and useful thing and it proves nothing about whether the pitch lands, so
it moves `demo.rehearsals` and never `narrative.mockPitches`.

**A mock pitch is never market evidence.** Twenty enthusiastic listeners say nothing about whether
contractors have this problem.
