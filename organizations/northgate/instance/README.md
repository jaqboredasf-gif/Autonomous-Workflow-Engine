# Northgate Mechanical — synthetic instance data

**Fictional.** Every person, supplier and job below is invented for the
second-customer rehearsal (`scripts/eval-second-customer.mjs`). Nobody named
here exists, every address is invented, and every email domain is
`example.invalid`, which cannot resolve.

It exists to answer one question: does `scripts/pcc-onboard.mjs` load a second
organization's reference data without any of it being Lippolis-shaped? So the
roles share **no name** with Lippolis's, the job numbers are a different format,
and the vendor codes are different.

The same five files a real design partner would fill in, in the same formats —
see `config/onboarding/README.md` for the column rules.
